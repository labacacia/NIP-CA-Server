# Security Policy

## Reporting

Use GitHub private vulnerability reporting: https://github.com/labacacia/NIP-CA-Server/security/advisories/new. Do not open a public issue. Include the affected version, reproduction conditions, and impact, with secrets and unrelated data removed.

Only the latest maintained branch and latest pre-release are supported unless maintainers state otherwise.

## Scope

CA keys, passphrases, operator keys, database credentials, issued state, and revocations are sensitive. Review all issuance, revocation, crypto, storage, API, and deployment changes.
